# Cloud-Native KML/KMZ to 3D Parser for Nigeria Infrastructure

## Spatial Question
How can complex KML/KMZ network traces across diverse urban and rural regions in Nigeria be efficiently parsed and converted into lightweight formats for seamless browser-based 3D web visualization?

## Study Area
Nationwide (with primary deployment focus across urban centers in Nigeria, such as Lagos, Abuja, and Ogun State).

## Datasets & Sources
* Field Survey KML/KMZ Network Traces (Source: Internal Network Engineering Data)
* Building Footprints - Nigeria (Source: [OpenStreetMap via Geofabrik](https://download.geofabrik.de/africa/nigeria.html))
* Road Network Lines - Nigeria (Source: [OpenStreetMap via Geofabrik](https://download.geofabrik.de/africa/nigeria.html))
* Administrative Boundaries - Nigeria (Source: [Humanitarian Data Exchange - HDX](https://data.humdata.org/dataset/cod-ab-nga))
